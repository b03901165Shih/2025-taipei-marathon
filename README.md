## Main features

| 功能 | 操作 | 輸出 |
|------|------|------|
| **分布圖** | 選賽事+賽別+分組 | 5分鐘區間完賽時間長條圖 |
| **查排名** | 輸入 `HH:MM:SS` | 全場+性別+細組精準 **PR%** |
| **查時間** | 輸入 **PR%** | 剛好超越的完賽時間 |
| **待匯入賽事提示** | 選到尚未匯入完整成績的賽事 | 顯示資料建置中的提示訊息 |

## Data pipeline / extensibility
- 前端會自動讀取 `window.marathonData` 中的所有賽事 metadata，因此新增賽事時只要補上對應的 `*_data.js` 檔案即可出現在選單中。
- `extract_excel_result.py` 已改為從 `events_config.json` 讀取賽事設定，新增賽事不必再修改 Python 腳本本體，只要新增設定即可。
- 目前 `events_config.json` 已包含 `2026南山人壽臺北國道馬拉松` 的設定與來源 URL，方便後續補上完整成績後直接生成正式資料檔。
